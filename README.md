# TVmaze Show Gallery

## Live site

View the deployed websit - https://maishafyruz.github.io/CSC372_assignment4/

## Project Description

TVmaze Show Gallery is a searchable TV show website built with HTML, CSS, and JavaScript. The site uses the TVmaze API to search for shows and display information about matching results.

Each show card includes the show name, summary, premiere date, last updated date and time, genres, average rating, main cast members, and a link to the show on TVmaze.

## Features

- Searches for TV shows by title or keyword.
- Displays up to 10 matching shows.
- Loads a default search when the page first opens.
- Uses a second API request to retrieve cast information for each show.
- Handles missing show information with clear fallback messages.
- Handles empty searches, no results, request errors, and rate-limited requests.
- Uses Flexbox to create a responsive gallery.

## API

Show and cast data are provided by the [TVmaze API](https://www.tvmaze.com/api).
